03

Decisions made that diverge from the original design docs

Two choices were made on this branch that differ from what main's architecture documents originally specified. They're flagged explicitly here so they're a team decision, not a silent drift.

Model access: OpenRouter instead of calling Claude directly The original architecture brief specified calling the Claude API directly. This branch instead goes through OpenRouter, which allows switching between many providers' models (including free ones) without changing the integration. See the model & pricing doc for the reasoning.
A free AI model, not a paid one, for the hackathon demo Cost isn't a concern for a demo, so a free model was chosen deliberately over a paid one, with a documented, tested tradeoff around occasional slowness. Switching to a paid model later is straightforward. See the known-risks doc.
